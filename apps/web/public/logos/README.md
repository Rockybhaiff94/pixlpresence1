# Pixel.gg Social Logo Extraction Pack

This pack contains 45 social/payment/gaming/crypto icon tiles cropped from the screenshot you supplied.

## Folders
- `tiles/`: 152×152 PNG crops retaining the dark rounded tile from the reference UI. These are the most faithful visual matches to the screenshot.
- `transparent-png/`: approximate foreground-extracted PNGs with transparent backgrounds. Some very dark marks can lose contrast; use the matching `tiles/` version when needed.
- `svg/`: clean brand SVGs generated from the locally installed Font Awesome Free Brands icon package for brands it supports. These are scalable but may not match the exact glyph variant/color shown in the screenshot.
- `contact-sheet.png`: labeled overview of all 45 extracted tiles.
- `manifest.json` / `manifest.csv`: ordered icon inventory and file paths.

## SVG coverage

Clean SVGs included for: apple-music, bitcoin, bluesky, discord, ethereum, facebook, github, gitlab, instagram, keybase, lastfm, linkedin, monero, patreon, paypal, pinterest, playstation, reddit, signal, snapchat, soundcloud, spotify, steam, telegram, threads, tiktok, twitch, vk, x, xbox, youtube.

## Screenshot identification note
The last dark N-shaped mark in row 2, column 12 is difficult to distinguish from this screenshot alone. It may be NameMC or OnlyFans; it is saved as `unknown-dark-n-mark`. Please verify it against the live site before assigning a platform name.
